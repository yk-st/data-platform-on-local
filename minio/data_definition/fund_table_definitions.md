# fund_nav_daily テーブル 各項目の定義

### `基準日` (date)
- **定義**: 基準価格が記録された日。
- **例**: `2025-04-01`

### `fund_id` (varchar(50))
- **定義**: 投資信託を一意に識別するID。
- **例**: `FND001`

### `基準価格` (decimal(12,2))
- **定義**: 当該日の1口あたり基準価額（日本円）。
- **例**: `11 023.45`

ようごしゅうでは、いつの時点のUSD/JPYが採用されるのかなど細かに書くことで説明の仕方とする。

# fund_master テーブル 各項目の定義

### `fund_id` (varchar(50))
- 定義: 投資信託を一意に識別するID。  
- 例: FND001

### `投資信託_分類` (varchar(20)) ― `fund_type`
- 定義: 投資信託の分類（アクティブ／インデックス）。  
- 例: ACTIVE

### `信託報酬_率` (decimal(5,2)) ― `expense_ratio_pct`
- 定義: 年率信託報酬率（%）。  
- 例: 1.20

### `有効レコード` (boolean) ― `is_active_record`
- 定義: マスタレコードが有効かどうかを示すフラグ。  
- 例: true
